# Notes

## Trees
A non linear hierarchical data structure consisting of Nodes connected by Edges

### Binary Trees
A tree where every node has $\le 2$ children

### Binary Search Trees
A complete binary tree where $\text{left} \lt \text{root} \lt \text{right}$

### AVL Trees
A self balancing binary search tree where left subtree and right subtree's height difference is at most 1

### RB Trees
A self balancing binary tree where no leaf-to-root path is more than twice as long as any other path.

---

## Hashing
It refers to the process of converting a raw input of arbitrary length to a scrambled string of fixed size

---

## Graphs
A non linear data structure consisting of Vertices connected by Edges

## DFS
Depth First Search
Visits as deep as it can before backtracking
Uses Stack (LIFO)

## BFS
Breadth First Search
Visits all nodes of the current level before going deeper
Uses Queue (FIFO)
